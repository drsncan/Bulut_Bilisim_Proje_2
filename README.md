## 🛠️ Kullanılan Teknolojiler

Proje, modern yazılım geliştirme standartlarına uygun olarak Backend ve Frontend katmanlarından oluşmaktadır:

**Backend (API Katmanı)**
* **Framework:** .NET Core Web API (C#)
* **Veritabanı:** SQL Server (Bulut entegrasyonuna hazır)
* **Güvenlik:** JWT (JSON Web Token) tabanlı kimlik doğrulama

**Frontend (Arayüz Katmanı)**
* **Kütüphane:** React.js
* **Derleme Aracı:** Vite
* **HTTP İstemcisi:** Axios

---

## 🚀 Öne Çıkan Özellikler

1. **Bulut Entegrasyonu:** Verilerin bulut ortamında güvenli yönetimi ve depolanması.
2. **Güvenli Kimlik Doğrulama:** JWT protokolü ile yetkilendirilmiş API uç noktaları.
3. **Duyarlı Tasarım:** Karanlık mod destekli ve tüm cihazlarla uyumlu modern kullanıcı arayüzü.
4. **CRUD İşlemleri:** Verilerin dinamik olarak listelenmesi, oluşturulması, güncellenmesi ve silinmesi.
